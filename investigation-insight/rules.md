# Investigation Insight — Shared Plugin Rules

These rules apply to **all skills** within the `investigation-insight` plugin.
Every skill must read and follow these rules before generating any output.

---

## Rule 1 — Language

- All SKILL.md files and internal skill logic must be written in **English**.
- Final reports and Q&A responses must be **translated to the user's language**.
- If the user has not specified a language, default to **Chinese (Simplified)**.

---

## Rule 2 — Citation & Data Integrity

This is the most critical rule. Investigation reports are only as good as their sources.

### 2.1 Always Mark the Data Source

Every data point, statistic, claim, or figure in the report **must** be tagged with
its source. Use inline citation format:

```
Revenue was $1.09 billion in FY2025. (Source: X-Energy IPO Prospectus S-1, Apr 2026)
```

For web-sourced data, cite the outlet and date:
```
Shares surged 27% on debut. (Source: CNBC, Apr 24 2026)
```

### 2.2 Source Priority Hierarchy

When multiple sources are available for the same data point, always prefer sources
higher in this hierarchy:

```
Tier 1 — HIGHEST PRIORITY (always prefer these)
  ├── Official company filings (SEC: 10-K, 10-Q, S-1, 8-K, Form 4)
  ├── Government sources (DOE, NRC, Fed, BLS, Census, Treasury)
  ├── Central bank publications (Federal Reserve, ECB, PBoC)
  ├── International institutions (IMF, World Bank, BIS, IEA, IAEA)
  └── Management statements (earnings call transcripts, official press releases)

Tier 2 — HIGH PRIORITY
  ├── Major financial data providers (Bloomberg, Reuters, FactSet, Refinitiv)
  ├── Established financial news (WSJ, FT, Barron's, The Economist)
  └── Reputable research institutions (CFA Institute, McKinsey, Brookings)

Tier 3 — ACCEPTABLE (use when Tier 1/2 unavailable)
  ├── Established general news outlets (NYT, BBC, AP, Axios)
  ├── Industry trade publications
  └── Company investor relations pages

Tier 4 — USE WITH CAUTION (flag explicitly)
  ├── Analyst blogs, Substack, Medium
  ├── Social media, Reddit, X/Twitter
  └── Any source with potential conflict of interest

```

Always cite the tier when using Tier 3 or below, e.g.:
```
(Source: TechCrunch, Apr 2026 — Tier 3, no official filing available)
```

### 2.3 No Data = Say No Data

If a data point cannot be found from any credible source:

- **Do NOT guess, estimate, or infer** the value.
- **Do NOT leave the field blank** without explanation.
- **Explicitly state**: `No data available from credible sources.`
- Optionally suggest where the data might be found in the future:
  ```
  Gross margin: No data available — not disclosed in S-1. Expected in first 10-Q post-IPO.
  ```

This rule is absolute. A report with honest gaps is far more valuable than one
with fabricated or speculative numbers.

### 2.4 Flag Outdated Data

Any data point older than **90 days** must be flagged:
```
Employee count: ~916 (Source: Rockville EDC, Mar 2026) ⚠️ may be outdated
```

### 2.5 Conflicting Sources

If two credible sources report different values for the same data point:
- Report both values and note the discrepancy.
- Prefer the higher-tier source.
- Do not silently pick one without explanation.

```
Revenue FY2025: $109.1M (Source: IPO Prospectus S-1) vs $162.9M (Source: ZoomInfo)
→ Using S-1 figure as it is the official audited filing (Tier 1).
```

---

## Rule 3 — Disclaimer

Every report generated by any skill in this plugin must end with:

```
---
⚠️ This report is for informational purposes only and does not constitute
financial, investment, or legal advice. Always verify data from primary sources
before making any investment decisions.
---
```

---

## Rule 4 — No Fabrication

- Never invent company names, executive names, ticker symbols, prices, or dates.
- Never present projections or forecasts as facts.
- Always distinguish between **historical data** (fact) and **analyst estimates** (opinion).

---

## How Skills Reference These Rules

Each SKILL.md should include at the top of its workflow section:

```
> 📋 Read and apply `/rules.md` before generating any output.
```
